# 홈페이지 자동 검사

홈페이지 파일을 수정한 뒤 실행합니다. Python 표준 라이브러리만 사용하며 설치할 패키지가 없습니다.

```bash
python3 tools/check_site.py
```

검사 항목:

- 내부 링크가 가리키는 HTML·파일 존재 여부
- 페이지 이동용 `#id`와 중복 ID
- 이미지·srcset·스타일시트·스크립트·CSS 이미지 경로
- 이미지의 `alt` 속성 누락
- 전화·문자 링크와 본문에 표시된 휴대폰 번호
- 검색 대상 페이지의 제목·설명·H1 누락과 제목·설명 중복
- 실제 페이지 주소와 canonical 일치 여부
- JSON-LD가 있을 때 JSON 문법 오류
- 사이트맵 XML 문법, 중복·누락·잘못된 페이지 주소

검색 정보 검사는 `check_search_metadata` 설정으로 켜집니다. 오류 페이지 `404.html`과 `noindex`로 지정한 페이지는 검색 대상에서 제외합니다. 사이트맵에는 나머지 HTML 페이지의 정규 주소를 각각 한 번씩 포함해야 합니다.

회사 도메인과 전화번호 기준은 `tools/site_check.json` 한 곳에서 관리합니다. 실제 번호가 바뀌면 홈페이지 수정과 함께 이 기준도 변경합니다.

오류가 있으면 파일명·위치·원인을 출력하고 종료 코드 1을 반환합니다. 정상일 때는 검사 개수와 `PASS`를 출력합니다.

검사 프로그램 자체의 검증:

```bash
python3 -m unittest discover -s tools/tests -v
```

GitHub에 변경을 올리거나 PR을 만들면 `Site integrity check`가 자동으로 실행됩니다. GitHub Actions에서 수동 실행도 가능합니다. 검사는 파일을 읽기만 하며 홈페이지를 수정하지 않습니다.

이 검사는 저장소 파일의 오류를 확인합니다. 외부 사이트 접속, 휴대폰 앱 실행, 모바일 화면 배치와 검색 순위는 검사하지 않습니다. 기존 GitHub Pages 배포는 별도로 실행되므로 검사 실패가 배포를 자동으로 차단하지는 않습니다.

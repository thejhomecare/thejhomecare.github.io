기존 망과 부속 상태 확인

기존 망에는 오염과 찢어진 부분이 있었습니다. 망을 교체하면서 틀 가장자리의 모헤어와 아래쪽 롤러도 살펴보니 함께 교체가 필요한 상태였습니다.

파손 롤러와 노후 모헤어 교체

기존 롤러는 녹이 슬고 파손돼 있었으며 바퀴가 남아 있지 않은 부속도 확인됐습니다. 손상된 롤러를 제거하고 새 롤러를 장착했습니다.

눌리고 삭은 모헤어도 새것으로 교체했습니다. 모헤어는 방충망과 창틀이 만나는 가장자리의 틈을 줄이는 부속입니다.

30메쉬 미세방충망과 모서리 마감

기존 틀에 국산 정품 30메쉬 모노필라멘트 미세방충망을 시공한 뒤 각 창에 다시 장착했습니다. 창틀 구조상 남는 모서리 틈에는 코너캡을 부착했고, 필요할 때 분리할 수 있도록 양면테이프로 고정했습니다.

김해 율하동원로얄듀크 방충망 교체 상담

지역과 아파트명, 대략적인 수량과 불편한 부분을 알려주세요. 망이 찢어졌는지, 방충망이 움직일 때 끌리거나 뻑뻑한지도 함께 말씀해 주시면 상담에 도움이 됩니다.

현장 상태에 맞춰 필요한 작업을 안내하며 부속 교체 범위와 비용은 작업 전에 먼저 설명드립니다. 김해·부산·창원·양산·밀양 지역에서 방충망 교체와 제작·수리를 진행합니다.

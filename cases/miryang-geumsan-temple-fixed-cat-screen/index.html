샤시 처짐과 외부 방범창으로 분리가 어려운 창

기존 방충망틀은 샤시가 처진 상태였고 외부에는 방범창이 있어 분리하기 어려웠습니다. 손상된 망을 제거한 뒤 기존 창 구조에 맞춰 새 고정형 방충망틀을 제작하는 방식으로 진행했습니다.

기존 틀에 겹쳐 설치한 고정형 방충망

현장에 맞게 틀 부재를 준비하고 블랙스텐망을 시공해 고정형 방충망을 제작했습니다. 새 틀은 기존 틀에 겹쳐 설치했습니다.

고양이가 밀어 망과 가스켓이 빠진 방충망

다른 창은 고양이가 방충망을 밀면서 망과 가스켓이 빠진 상태였습니다. 해당 방충망은 분리해 블랙스텐망으로 교체하고 모헤어도 함께 정비했습니다.

이번 현장 관련 질문

샤시 처짐과 외부 방범창으로 틀 분리가 어려운 창은 손상된 망을 제거한 뒤 고정형 방충망틀을 새로 제작해 기존 틀에 겹쳐 설치했습니다.

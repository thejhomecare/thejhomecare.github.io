특대 방충망 틀 상태 확인

베란다 방충망의 크기가 커 기존 틀을 계속 사용할 수 있는지 먼저 확인했습니다. 새 틀 제작이 필요할 가능성에 대비해 장비와 자재를 준비해 방문했습니다.

확인 결과 기존 틀을 사용할 수 있어 틀 제작 비용 추가 없이 작업했습니다.

미세방충망과 롤러·모헤어 교체

기존 틀에 미세방충망을 시공했습니다. 고장 난 롤러를 교체하고 모헤어도 새것으로 바꿨습니다. 이번 현장의 롤러·모헤어 교체는 서비스로 진행했습니다.

베란다·복도 창 설치 완료

작업한 방충망을 베란다와 복도 쪽 창에 다시 설치했습니다. 특대 방충망의 기존 틀을 살리면서 망 교체와 부속 정비를 마무리했습니다.

오래된 방충망 틀도 재사용할 수 있나요?

틀 상태에 따라 달라집니다. 오래된 틀은 분리하거나 다시 설치할 때 모서리가 손상될 가능성이 있어 작업 전에 안내합니다. 이번 현장은 기존 틀을 재사용했습니다.
